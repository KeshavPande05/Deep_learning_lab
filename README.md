# Deep Learning and Applications Laboratory

This repository contains the laboratory experiments for the **BDBP309: Deep Learning and Applications Laboratory** course. The experiments focus on implementing fundamental and advanced deep learning models using **PyTorch**.

---

## 📚 Course Objectives

The objective of this laboratory is to gain hands-on experience with:

- Artificial Neural Networks (ANN)
- Convolutional Neural Networks (CNN)
- Recurrent Neural Networks (RNN)
- Long Short-Term Memory (LSTM)
- Gated Recurrent Units (GRU)
- Time Series Prediction
- Character-Level Sequence Modeling
- Generative Adversarial Networks (GANs)

---

## 🧪 Laboratory Experiments

| Lab No. | Experiment |
|---------:|------------|
| **Lab 01** | Building Neural Networks (NN) using PyTorch to predict patterns from real-world data |
| **Lab 02** | Building Convolutional Neural Networks (CNNs) to classify images based on patterns |
| **Lab 03** | Implementing a Recurrent Neural Network (RNN) |
| **Lab 04** | Implementing RNN variants (LSTM and GRU) using PyTorch |
| **Lab 05** | Training a Simple RNN for Time Series Prediction |
| **Lab 06** | Implementing a Character-Level Sequence RNN |
| **Lab 07** | Building Generators and Discriminators using Convolutional, Batch Normalization, and Fully Connected Layers (GAN Basics) |

## 🎯 Learning Outcomes

After completing these experiments, you will be able to:

- Understand the fundamentals of deep learning.
- Build neural networks using PyTorch.
- Train CNNs for image classification.
- Implement RNNs for sequential data.
- Understand and implement LSTM and GRU architectures.
- Perform time series forecasting.
- Build character-level language models.
- Understand the basics of Generative Adversarial Networks (GANs).
